Welcome to the official GitHub organization of **Adung** ([https://adung.top](https://adung.top)), an independent, bootstrapped creator intelligence startup based in Vietnam.

We engineer high-performance, local-first desktop workstations and developer tools that empower video creators, investigative storytellers, and media production teams to discover high-velocity content opportunities and develop original creator-led scripts from research insights.

---

## Flagship Products & Ecosystem

### 1. YouTube Adung Commercial (Workstation v1.2)
- **Standalone Desktop Application:** Engineered for Windows 10 & 11 (64-bit), bundling all runtimes with zero external dependencies.
- **Deep Transcript Extraction:** Extracts complete timestamped spoken transcripts (4,000 to 18,000+ words) in under 4 seconds to inspect 3-act narrative arcs, retention drop-off patterns, and hook pacing.
- **110 Curated Niche Libraries:** Real-time Views-Per-Hour (VPH) velocity multipliers across 65 Faceless/AI storytelling niches and 45 Real-life creator niches.
- **Local-First Privacy:** All project catalogs and transcripts are indexed locally with hardware-bound Windows DPAPI encryption.

### 2. Adung YouTube MCP Server (`adung-mcp`)
- Native implementation of Anthropic’s open **Model Context Protocol (MCP)** specification.
- Exposes tools for YouTube transcript ingestion, competitor velocity queries, and creator DNA extraction directly to **Claude Desktop** and **Claude Code**.
- Operates locally over `127.0.0.1` using Bring-Your-Own-Key (BYOK) architecture.
